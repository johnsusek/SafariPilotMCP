Every agent session now works in a separate Safari window, and pages read closer to how they look.

## New

- **A window per session:** each MCP session opens tabs in a window of its own and can act only on tabs it opened. SafariPilot closes those tabs once the session ends or disconnects. Tabs left behind by a session that has ended are closed at launch.
- **Pilot tab glow:** pilot tabs have a glow around the edge so you can tell them apart from your own. Screenshots leave it out.
- **Tables and grids:** `get_page_text` with `format: "markdown"` reads ARIA tables and grids as markdown tables, with checkbox states, and `read_page` shows which column a table is sorted by. Code editors such as CodeMirror come back as fenced code blocks with their language.
- **Scrollable boxes:** scrollable containers get a ref, and `scroll` reports the container's own scroll offset.

## Changed

- **Server name:** the MCP server is now called `SafariPilot`, so clients show tool names like `mcp__SafariPilot__click`. Permission rules written for `mcp__safaripilot__*` need the new name.
- **Modal dialogs:** with a modal dialog open, reads and change reports leave out the page behind it, the same way they skip `aria-hidden` and `inert` content. When the dialog closes, the page that comes back is reported in one line.
- **Change reports:** elements that re-render are matched by role and name, so the report no longer shows them as removed and added again. A reordered list is reported as a count of moved items. If a report is too long to show in full, new content comes before removed lines.
- **Server instructions** are rewritten in the order an agent works: tabs, reading, acting, then errors.
- `page_fetch` reads response bodies up to 5 million characters.
- `browser_batch` steps take the client's prefixed tool name as well as the short one.

## Fixed

- **Clicks that missed:** `click` now works on links that WebKit folds into a larger element (for example store cards), on elements Safari exposes only as static text, and on elements whose pressable ancestor is centered off the element. If a click changes nothing on a widget that listens for pointerdown, the reply says to try the keyboard.
- **New tabs in your windows:** `tab_create` checks which window Safari actually put the tab in, and moves the tab to a window of its own if it landed among your tabs.
- **Stuck dialogs:** an animation started by an action now finishes even though the pilot window is behind yours. Before, a dialog closing with an animation could stay on screen.
- **Keys:** keys sent through the page script include legacy key codes, so jQuery handlers see them, and the up and down arrows step number fields.
- **Reading:** framesets, rich-text editor bodies (TinyMCE), contenteditable line breaks, checkboxes and radios with no box of their own, and words split by inline markup or set apart by spacing all read correctly. `find` matches plain-text elements by the text they show.
- **Empty reads:** reading a PDF fails with an error instead of returning nothing. If a page hasn't rendered any text yet, the read says so. Markdown cut off by the text budget is marked as truncated.
- `tab_create` returns even if the window it brings forward has closed, and closing tabs skips Safari windows that report no role.
