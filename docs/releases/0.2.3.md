More clients and a tab placement fix.

## Added

- **Set up more clients:** the Clients pane and the new Set Up Client menu now configure ChatGPT and Codex, Cursor, VS Code and LM Studio alongside Claude Desktop and Claude Code. Other Clients copies a standard `mcpServers` entry for anything else.

## Fixed

- **Agent tabs in your window:** after Safari renumbered its windows, `tab_create` could open agent tabs in one of your own windows. It now reuses the pilot window only while every tab in it is a pilot tab.
