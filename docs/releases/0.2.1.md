A new toolbar icon, a simpler `page_fetch`, and releases built in the open.

## Changed

- **Toolbar icon:** Safari's toolbar shows a monochrome SafariPilot icon sized for the toolbar, instead of the app icon.
- **`page_fetch` sends any method:** the **Allow page_fetch Writes** setting is gone. `javascript` could already send requests with any method, so the setting restricted nothing. Requests still go only to the tab's own origin or hosts in its network log, with secrets hidden.
- **Releases:** each release is built, signed and notarized in GitHub Actions from its tagged commit, with a SHA-256 checksum beside the DMG. SafariPilot also installs with `brew install --cask johnsusek/tap/safaripilot`.
