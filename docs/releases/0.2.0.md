Claude now does more per call: actions report what changed on the page, elements can be targeted by name, reads can be narrowed, and a site's own API calls can be sent again from inside the page.

## New

- **`page_fetch`:** sends a request from inside a tab's page, with its cookies and origin, either to a URL or as a replay of a request from `read_network_requests`. SafariPilot fills in the replay's auth and CSRF headers, which Claude never sees. Only GET and HEAD are sent unless you turn on **Allow page_fetch Writes** in the **General** pane.
- **Replies show what changed:** `click`, `form_input`, `key`, `drag` and `file_upload` end with what they added, changed or removed on the page. The reply waits for the page to settle, including any fetch and XHR calls the action started.
- **Act by name:** action tools take `name` and `role` in place of `ref`, so Claude can click "Sign in" without reading the page first. When more than one element matches, nothing is done and the candidates are listed with their refs.
- **Leaner reads:** `read_page` with `viewport` returns only what is on screen. `get_page_text` with `format: "markdown"` keeps headings, lists, link URLs and tables, and with a `ref_id` returns just that element.
- **Timing:** the **Activity** log shows how long each phase of a command took.

## Fixed

- `form_input` sets sliders, ARIA ones included (such as YouTube's seek bar), with real arrow, Home and End keys.
- A compact JSON body that held a URL with a query string was read as a form body, so secret-named values in it were shown in network logs. They are now hidden.

## Changed

- The **Clients** pane shows **Already set up** when Claude Desktop or Claude Code already runs SafariPilot, instead of adding a second entry.
- SafariPilot is now MIT licensed.
