First release. SafariPilot lets Claude use your signed-in Safari over MCP, in its own tabs, with Safari left in the background.

Open the DMG, drag SafariPilot to Applications, open it and follow [setup](https://github.com/johnsusek/SafariPilotMCP#install). Needs macOS 26 and Safari 27.

## What's in it

- **Tabs:** `tabs_list`, `tab_create`, `tab_select`, `tab_close`, `navigate`, `resize_window`
- **Reading:** `read_page`, `find`, `get_page_text`, `screenshot`, `wait`
- **Acting:** `click`, `form_input`, `key`, `scroll`, `scroll_to`, `drag`, `file_upload`, `handle_dialog`, `browser_batch`
- **Debugging:** `javascript`, `read_console_messages`, `read_network_requests` with fetch and XHR bodies
- Real clicks and key presses through Accessibility, checked after each action
- Same- and cross-origin iframes, read and acted in
- Approval per client, access to its own tabs only, and secrets hidden in fields, URLs, cookies, headers and bodies
- Every failure names a code, whether to retry, and what to do next
- One-click setup for Claude Desktop and Claude Code

## Known limits

- No hover. Drag uses scripted events, which some drag libraries ignore.
- Safari 27 skips network logging for a new tab's first page load ([WebKit bug 315367](https://bugs.webkit.org/show_bug.cgi?id=315367)); later loads are logged.
