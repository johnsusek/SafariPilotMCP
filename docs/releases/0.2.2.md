## Changed

- **Verifiable DMG:** each release now carries a build provenance attestation. `gh attestation verify SafariPilot-0.2.2.dmg --repo johnsusek/SafariPilotMCP` confirms the DMG was built by this repo's release workflow from its tagged commit.

## Fixed

- **Tables in markdown reads:** a cell holding a backslash before a pipe, such as `a\|b`, no longer splits into two cells.
