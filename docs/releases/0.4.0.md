The app can take SafariPilot out of a client's setup, and clicks and drags work on more pages.

## New

- **Remove clients:** the Clients pane now shows each client's icon and, if SafariPilot is set up, a Remove button. Remove deletes every entry that runs SafariPilot and forgets their credentials. 
- **Help menu:** the Help menu opens topics on security, troubleshooting and the tools.
- **Activity log:** Errors Only and Keep Log toggles in the Activity toolbar and the log menu. A kept log is saved to Application Support and loaded on the next launch.

## Changed

- **browser_batch:** a failed read, or `javascript` that a page's Content-Security-Policy refuses, lets the batch go on.
- **Tools pane removed:** the list of tools has moved to the new Help menu.

## Fixed

- **Hover handlers:** a synthetic click now also fires synthetic cursor events (pointerover, mouseenter, mousemove and the rest), so links that attach their click handler on hover work. 
- **Links that open a tab:** `click` presses a link through its AXLink even when Safari exposes its text as static text, so `target="_blank"` links open their tab.
- **Timeouts behind other windows:** drags on a covered page, and clicks that open a tab in front of the page, no longer run into the 15 s content timeout.
- **AutoFill popups:** an AutoFill list open on a form field no longer makes every page tool fail with `safari_unavailable`.
- **Password fields:** setting a password field fires `input` and `change`, so pages that track their fields see the value.
- **Reading:** a cleared contenteditable reads back as empty, and absolutely positioned rows (virtualized lists such as TanStack Virtual) read as separate lines.
- **Duplicate extension:** installing unregisters every SafariPilot copy outside /Applications, so Safari lists one extension.
